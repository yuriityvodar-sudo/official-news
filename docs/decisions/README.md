# Decisions, one file each

Every decision that changes how we build gets its own file here, through a pull request: `YYYY-MM-DD-short-name.md`. One file each, so two open pull requests never conflict in the log. The decisions up to 30 Oct 2026 are the table in `docs/decisions.md`.

A file says, in a few lines:

- **Decision:** what we do now, and what it replaces (a file here, or a row of the old table by its date and first words).
- **Why:** the reason, with the numbers or the words that led to it.
- **Status:** Proposed (waiting for the other person's confirmation), or Agreed (who, when).

To read the log newest first: `ls -r docs/decisions/`.
