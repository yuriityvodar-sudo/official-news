# Settings gets Manage subscription; the chat's extra usage line goes (#146)

- **Decision:**
  - **Manage subscription.** While the AI agent is paid, Settings shows a row "Manage subscription" in a group of its own above About. It opens Apple's sheet for managing subscriptions (StoreKit 2's `showManageSubscriptions(in:)`, through `in_app_purchase_storekit`, now a direct dependency), where the reader cancels or changes it; if the sheet cannot open, the App Store's subscriptions page. Without a paid subscription the row is not there. In five languages: "Manage subscription", «Управлять подпиской», «Керувати підпискою», "Gestionar suscripción", "Abo verwalten".
  - **No line while extra usage is spent.** Over the chat's field only "80% of this week's usage used · resets Monday" shows, from 75% of the week's usage until it is used up. "Using extra usage", shown once the week's usage was used up while a pack was being spent, is gone in all five languages; the card with "Get more usage" stays for when nothing is left. This changes that one line of `2026-11-04-weekly-usage.md`; the rest stays.
  - **The release:** both go in the first release: store build 65 from main is submitted instead of 64 (Roman, 5 Nov: «Да, ждём 65»).
- **Why:** Roman, 5 Nov, on TestFlight 64: «где отменить подписку? в приложении этого нет». A subscription bought in TestFlight with a real Apple ID is not listed in the iPhone's Settings, so only a sheet the app opens can cancel it; for the App Store it spares the reader the way through Settings › Apple ID › Subscriptions, as Apple's guidelines for subscriptions suggest. And the "＋ Using extra usage" capsule «выглядит как кнопка, но не нажимается», isn't needed, and the line was agreed to show only as the usage runs out; App Review would see it right after buying a pack, as the review notes ask.
- **Status:** Proposed (Roman's Claude, on Roman's word of 5 Nov)
